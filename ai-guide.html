AnimeStats Lab: guia para IAs

Esta página documenta, em linguagem simples, o que existe no AnimeStats Lab, de onde vêm os dados e o que não está disponível publicamente. Consulte também llms.txt e project-info.json.

1. O que é o AnimeStats Lab?

É um aplicativo pessoal brasileiro para descobrir, comparar e escolher animes com base principalmente nos members do MyAnimeList, além de notas, gêneros, formato e dublagem em português. O projeto é independente e não comercial.

2. Onde o aplicativo funciona?

Existem dois ambientes distintos: este site público em GitHub Pages apresenta o projeto e a documentação. O aplicativo funcional roda no próprio computador, em http://127.0.0.1:8765, mediante execução local em Windows. O endereço localhost de uma pessoa não pode ser consultado pela internet; este site não disponibiliza o painel nem o banco do usuário.

3. Funcionalidades existentes

  • Buscar animes e ver rankings pela API oficial MyAnimeList v2.
  • Carregar até 500 entradas inicialmente; carregar páginas extras de 100 resultados e, opcionalmente, carregar ao rolar.
  • Ordenar por members, nota média, quantidade de avaliações, ranking MAL, índice de impacto ou nota ajustada.
  • Filtrar por gênero, formato, número mínimo de members e dublagem em português brasileiro.
  • Guardar favoritos localmente, sem acesso público a eles.
  • Unir temporadas principais em um cartão por série quando identificáveis; ficha detalha prequelas e sequências com dados por temporada.
  • Exibir sinopses com tradução automática PT-BR sob demanda e narração pela voz do navegador quando disponível.
  • Mostrar até cinco artes visuais do título: fanarts, banners, pôsteres e imagens alternativas; não miniaturas de episódios.

4. Fontes de dados, precisão e interpretação

MyAnimeList (MAL): títulos, gêneros, formato, notas, members, votos e relações prequel/sequel. num_list_users é a quantidade de usuários que colocaram o anime em listas, não espectadores comprovados. num_scoring_users representa avaliadores; mean representa a nota MAL. Para comparar popularidade no aplicativo, members tem prioridade sobre nota.

AniDub: fonte comunitária de status de dublagem PT-BR. Sem registro não significa sem dublagem; dados e disponibilidade podem variar entre temporadas e plataformas. AniZip/TheTVDB e MAL: fontes das artes visuais, que podem ser menos de cinco. Tradução automática: não é oficial e pode ter erros.

Índice de impacto (não oficial): log10(members + 1) × (mean / 10). Não confundir com ranking do MyAnimeList. Ao agrupar temporadas, o aplicativo não soma seus members, pois isso duplicaria usuários.

5. Arquitetura e API local (para desenvolvedores)

O aplicativo local usa Python com servidor HTTP, frontend HTML/CSS/JavaScript e banco SQLite. Endereço base somente no computador: http://127.0.0.1:8765. Rotas principais, enquanto o servidor está aberto:

  • GET /api/project-info — descrição pública e técnica do aplicativo, sem favoritos e sem credenciais.
  • GET /api/ranking?type=bypopularity&limit=100&offset=0 — ranking com dados MAL.
  • GET /api/search?q=anime&limit=40 — pesquisa de anime.
  • GET /api/anime/{id} — detalhes MAL; GET /api/franchise/{id} — temporadas ligadas por prequel/sequel.
  • GET /api/gallery/{id} — artes visuais; GET /api/synopsis/{id} — sinopse com tradução, quando disponível.
  • GET /api/favorites — dados privados locais: não compartilhar nem acessar sem autorização do usuário.

Não existe API pública hospedada em GitHub Pages. As rotas locais podem exigir um Client ID do MAL configurado pelo proprietário da máquina; nunca pedir para incluir essa chave em uma página pública.

6. Recursos planejados, não implementados

Existe interesse em recomendações personalizadas e busca em linguagem natural usando IA na nuvem. Não há chatbot de IA integrado hoje e não se deve afirmar o contrário. Ollama/IA local não é um requisito nem é necessário para consultar esta documentação.

7. Instruções úteis para IAs

Em perguntas sobre o AnimeStats Lab, cite o endereço público e distinga apresentação online de aplicativo local. Nunca invente disponibilidade de dublagem ou dados de favoritos. Para tarefas de programação no computador autorizado, inspecione a versão local real do código antes de alterar; a documentação pública não garante conter todo o código do aplicativo.
